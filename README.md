# 8192分の1

左右どちらかを選び続けるだけのゲーム。当たり(1/2)を引けば1段前進、はずれた瞬間スタートに逆戻り。13連続的中でたどり着く **1 / 8192** が目標。

**プレイ:** https://kaikomziu.github.io/one-in-8192/

- 🪙 確率のはしご表示（1/2 → 1/8192 → その先へ）
- 🎬 効果音・画面ゆれ・フラッシュ・パーティクルなど派手な演出（連続数で音階/熱が上昇）
- 📊 統計: 総試行・勝率・最高連勝・到達回数・最長連敗・プレイ時間
- 📋 確率表: 各段に到達した回数
- 🏅 実績 54種（到達・試行数・転落・連敗・強運・特殊）
- 🤖 オートモード（1/8192 を1回達成すると解禁、失敗で停止オプション）
- 🌍 世界ランキング（歴代最高連勝を Supabase 経由で共有・順位確認）
- セーブはブラウザ内（localStorage）。PC（← →キー）/スマホ対応。
